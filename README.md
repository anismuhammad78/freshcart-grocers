# FreshCart Grocers

A responsive grocery landing page created as part of my frontend web development internship at Ezitech.

**Live Site:** https://anismuhammad78.github.io/freshcart-grocers/

## Project Overview

FreshCart Grocers is a modern and responsive grocery website landing page designed to provide users with an easy and attractive way to explore fresh food products.

The website includes:

* Responsive navigation bar
* Hero section with tagline
* Product categories
* Featured products
* Services section with a responsive grid
* Pricing section with three membership plans
* About section
* Visit Us section
* Contact form with live validation and success toast
* Shop Now button
* Mobile responsive design
* Smooth navigation between sections
* Back-to-top button

## How to Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/anismuhammad78/freshcart-grocers.git
   ```
2. Open the project folder:
   ```
   cd freshcart-grocers
   ```
3. Open `index.html` directly in your browser, or serve it with a local server (e.g. VS Code's Live Server extension) for the best experience.

No build step, package installs, or dependencies are required — this is a static HTML/CSS/JS site.

## How to Deploy (GitHub Pages)

1. Push all files to the `main` branch of the GitHub repository.
2. Go to the repository's **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder, then save.
4. GitHub will publish the site at `https://<username>.github.io/<repo-name>/` within a minute or two.
5. Any future push to `main` automatically updates the live site.
